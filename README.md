# 🏠 Hostel Finder

A beginner-friendly hostel and PG finder web application built with **HTML, CSS and JavaScript**.

## Features

- Search hostels by city/location
- Filter by Boys, Girls and Co-ed
- Filter by monthly rent
- Hostel detail popup with amenities, rating and contact
- Login popup UI
- Responsive design for desktop and mobile
- Clean and simple user interface

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
hostel-finder/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Use the search and filters to explore hostels.
